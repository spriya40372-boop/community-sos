# 🚨 Community SOS & Emergency Response Platform

A real-time emergency response and location-aware community safety hub built with Node.js, Express, Socket.io, and Leaflet JS.

## ✨ Features
* 📍 **Live Interactive Map:** Displays user locations using Leaflet.js.
* ⚡ **Real-Time SOS Alerts:** Broadcasts immediate emergency alerts to all connected community members via WebSockets.
* 💬 **Live Community Chat:** Real-time messaging with automatic scroll position updates.
* 📞 **Quick-Dial Hotlines:** Instant click-to-call access to national emergency services (112, 100, 108, 1091).

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript (ES6+), Leaflet.js
* **Backend:** Node.js, Express.js, Socket.io
* **Deployment:** Render
